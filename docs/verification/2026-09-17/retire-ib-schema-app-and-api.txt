1. A store written by main opens on this branch with nothing lost

   Course.targetGrade is gone from the SwiftData model. A throwaway unit test
   on main wrote an on-disk store on the iPhone 17 simulator (Xcode 26.6). A
   throwaway test on this branch then opened it. Neither test is committed.
   Both suites passed, with 157 tests each: the 156 committed tests plus the probe.

   Written by main (a copy taken before the branch ran):
     ZCOURSE: Z_PK,Z_ENT,Z_OPT,ZTARGETGRADE,ZCREATEDAT,ZCOLORKEY,ZDISPLAYNAME,ZCOURSETEMPLATEID,ZID,ZREMOTEID

2. What create_course receives from the app

   Swift leaves a nil optional out of the JSON. main's own Params struct
   (template, level and target grade all nil) encodes as:
     {"p_color_key":"red","p_display_name":"Biology"}
   ProfileServiceTests pins the branch's body to those two names, using the
   Supabase client's own encoder.
